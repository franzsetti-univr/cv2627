# cv2627

Computer Vision course material for the 2026-27 academic year at the University
of Verona, Master's degree programme in Computer Engineering for Intelligent
Systems.

## Python environment

The project uses Python 3.11. From the project folder, create and activate a
virtual environment in PowerShell, then install the dependencies:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

The required packages are NumPy, Matplotlib, and OpenCV. The `venv` folder is
excluded from Git.
